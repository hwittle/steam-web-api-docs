# Steam Web API Documentation
An unofficial, community-created documentation resource for the Steam Web API.

## Disclaimer
This documentation is an independent project and is not affiliated with, endorsed by, or associated with Valve Corporation. Steam and the Steam Web API are trademarks of Valve Corporation.

For official Steam Web API information, visit the [official Steam API documentation](https://steamcommunity.com/dev).

## About
This documentation aims to provide clear, structured, and developer-friendly reference material for the Steam Web API, including endpoint descriptions, request parameters, example requests and responses, and error handling guidance.

## Getting Started
Documentation is available at: https://hwittle.github.io/steam-web-api-docs/
